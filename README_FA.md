# ربات موزیک‌یاب ایرانی

ربات تلگرام برای جست‌وجوی عنوان آهنگ و نام خواننده در کاتالوگ عمومی Deezer، نمایش اطلاعات آهنگ، پیش‌نمایش ۳۰ ثانیه‌ای در صورت موجود بودن و لینک‌های جست‌وجوی وب برای عبارت‌های متنی.

## امکانات نسخه اولیه
- جست‌وجو با پیام متنی
- نمایش عنوان، خواننده، آلبوم و مدت آهنگ در صورت وجود اطلاعات
- پیش‌نمایش کوتاه و لینک شنیدن در Deezer در صورت موجود بودن
- لینک جست‌وجوی عبارت در وب و YouTube؛ برای جمله‌های ترانه مفید است
- رابط فارسی

## محدودیت مهم
جست‌وجوی عمومی Deezer عمدتاً برای نام آهنگ و هنرمند است و جست‌وجوی متن ترانه را تضمین نمی‌کند. برای جمله‌های ترانه، ربات لینک‌های جست‌وجوی وب ارائه می‌دهد. این نسخه دانلود غیرمجاز آهنگ‌های دارای حق نشر را انجام نمی‌دهد و فقط لینک‌های شنیدن/پیش‌نمایش و منابع مجاز را نمایش می‌دهد.

## اجرا
1. Python 3.11 یا جدیدتر نصب باشد.
2. `pip install -r requirements.txt`
3. متغیر محیطی `BOT_TOKEN` را با توکن BotFather تنظیم کنید.
4. اجرا: `python bot.py`

## متغیر محیطی
- `BOT_TOKEN`: توکن محرمانه ربات تلگرام. هرگز آن را در GitHub قرار ندهید.

## استقرار روی هاست
Start command: `python bot.py`
Environment variable: `BOT_TOKEN` = توکن ربات
